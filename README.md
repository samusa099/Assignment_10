## 📌 Overview

A polished PSD-to-HTML product landing page featuring responsive sections, pricing, testimonials, contact content, and interactive UI components.

The repository is organised as a self-contained project that can be downloaded, reviewed, and run locally with minimal setup.

---

## ✨ Key Features

- ✅ Responsive navigation and hero presentation
- ✅ Product feature and device showcase sections
- ✅ Customer testimonial carousel
- ✅ Pricing-plan cards and calls to action
- ✅ Contact section with embedded map
- ✅ Custom responsive breakpoints and reusable styling

---

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and semantic content |
| **CSS3** | Layout, typography, responsiveness, and visual styling |
| **Bootstrap 5** | Responsive grid, utilities, and UI components |
| **JavaScript** | Interactive behaviour and browser-side logic |
| **jQuery** | DOM helpers and plugin integration |
| **Owl Carousel** | Responsive testimonial/content carousel |
| **Font Awesome** | Interface and social icons |

## 🚀 Run Locally

```bash
git clone https://github.com/samusa099/Assignment_10.git
cd Assignment_10
```

Open `index.html` directly in a modern browser, or use the **Live Server** extension in Visual Studio Code for automatic refresh.
